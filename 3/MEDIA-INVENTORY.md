# Inventaire média

Les images architecturales actuellement utilisées sont des visuels temporaires distants issus d’Unsplash, uniquement pour le développement.

| Usage | Source | Statut |
|---|---|---|
| Hero / CTA | Unsplash, URLs intégrées dans `dist/styles.css` | `[A REMPLACER — PHOTO CLIENT]` |
| Marbre / sols / verre | Unsplash, URLs intégrées dans `dist/styles.css` | `[A REMPLACER — PHOTO CLIENT]` |
| Secteurs | Unsplash, URLs intégrées dans `dist/styles.css` | `[A REMPLACER — PHOTO CLIENT]` |
| Logo | `dist/assets/altium-logo.webp` | Asset officiel fourni par ALTIUM |

Le brief demandait des vidéos cinématiques et des composants shader React. Le site actuel est un build statique : le shader est reproduit avec des couches CSS animées (fallback GPU léger), sans vidéo ou URL inventée. Les photographies distantes restent des visuels temporaires à remplacer par des médias officiels ALTIUM.
